# Google Sheet Structure

## Weekly Ijtima User Details
Create one Google Sheet with these tabs:

### Users
User ID | Username | Password Hash | Name | Role | Active | Photo URL | Region | State | Division | District | Area | Pincode

### Locations
Region | State | Division | District | Area | Pincode

### Audit Log
Timestamp | User ID | Action | Details

### Notifications
Timestamp | Week Date | Location | User ID | Status

## Yearly report tabs
The Apps Script automatically creates:
`Weekly Ijtima Report 2026`
`Weekly Ijtima Report 2027`
etc.

Columns:
Report ID | Week Date | User ID | Region | State | Division | District | Area | Pincode | Participants | Volunteers JSON | Status | Timestamp
